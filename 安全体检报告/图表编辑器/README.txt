Word 图表编辑器（离线）

1. 用 Edge 或 Chrome 打开 index.html。
2. 选择原始 DOCX。左侧会显示 Word 内的全部图片。
3. 选择对应的报告 HTML。编辑器从其中读取 SECURITY_REPORT_DATA，列出已支持的业务图表。
4. 在左侧选择需要替换的 Word 图片；在中间修改分类名称和数值；预览确认后点击“应用图表到选中图片”。
5. 点击“生成新版 Word”。浏览器下载“原文件名-图表已更新.docx”。原文件不会被覆盖。

也可先在左侧选中图片，点击“用自选 PNG 替换选中图片”，用于当前版本尚未支持的数据图或自定义图。

支持的图表
- ECharts 图表、各项数据卡片（domText）、嵌入式看板（iframe），以及 3.2.5 典型案例的攻击链双线时间轴。
- 攻击链的报告 HTML 里是服务端烘焙好的静态标记，没有 data-field 也没有浏览器端渲染器，所以编辑器用编辑后的
  attackTimeline / defenseTimeline 在 iframe 内重建整块时间轴，再整体截图盖回 Word 原图。
  每行三个输入框依次是「阶段名 / 卡片标签」「时间」「说明」；名称留空表示续接上一张卡片。
- 3.2 的「Top5资产的风险类型」在报告里是按风险类型堆叠的柱状图，一根柱子可能同时包含病毒木马/C2、漏洞利用、
  暴露面、漏洞、弱口令中的多段。所以每行给的是 5 个分段输入框加一个只读合计，改的是具体某一段而不是总数；
  合计和 Word 里那根柱子的高度始终一致。注意该图表卡片下方的风险明细表格是正文表格、不是截图，不受编辑器影响。
- 3.1 的三张环形图（资产类型分布 / 资产防护统计 / 安全组件分布）类目颜色在报告里是按名字查表的，名字不在表里
  会变成和「其它」一样的灰色。所以这三张图的类目名是只读的，新增时从下拉里选一个还没出现的固定类目补回来，
  名单补齐后新增控件不再出现。安全组件分布的数据源只输出有值的类目，缺类目的情况只出现在它身上。

安全与限制
- 不上传文件，也不请求网络。
- 仅替换用户确认的 word/media 图片，不修改正文、表格、页眉页脚或图片关系。
- 只按 drawing 元数据（descr="sr-component:XXX"）识别图片。截图是"正文里有这个章节才截"的，可选的典型案例
  会把之后每张 imageN.png 都往后推一位，按文件名匹配必然错位，所以文件名映射已完全移除。生成器从
  2026-07-20 起为每张截图写入元数据；更早生成、没有元数据的 Word 文件不再支持编辑，选中后会提示"没有数据映射"。
- 元数据里的 id 认不出来时不做任何猜测，直接视为"这张图没有可编辑图表"（例如附录的优先矩阵）。
- 预览用 1440px 宽的离屏 iframe 重绘组件。报告版心有 max-width，该宽度已超过上限，因此重绘几何与导出时一致。
- 需要当前 Edge/Chrome 支持 CompressionStream 与 DecompressionStream。请勿用 IE 或旧版浏览器打开。
